# Показ Nova Cinema на этой машине

Всё работает локально: интернет нужен только для постеров — они лежат на TMDb.

## Запуск

```powershell
powershell -ExecutionPolicy Bypass -File demo.ps1
```

Скрипт поднимет API и фронтенд в двух окнах и напечатает ссылки для входа.
Закрыть демо — закрыть эти окна.

Если хочется вручную, три команды в трёх терминалах:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

```powershell
Set-Location frontend; npm run dev
```

```powershell
.\.venv\Scripts\python.exe demo_login.py
```

## Что показывать

| Ссылка | Кто вы | Что видно |
|---|---|---|
| `http://localhost:5173` | гость | каталог, поиск, карточка фильма, расписание, «О нас» |
| ссылка «Администратор» из `demo_login.py` | владелец | всё выше плюс админ-панель на `/admin` |
| ссылка «Алина Каримова» | зритель | личный кабинет с билетами, историей и QR |

Приложение авторизует пользователя через Telegram. В браузере Telegram нет,
поэтому `demo_login.py` подписывает вход тем же ботовым токеном, который
проверяет сервер: те же проверка подписи, JWT и роли, что и внутри Telegram.
Никакого обходного пути в приложении для этого не добавлено. Ссылки живут сутки.

Открывайте в браузере на узком окне (F12 → режим телефона) — интерфейс
рассчитан на телефон.

## Сценарий на десять минут

1. **Каталог.** 22 фильма, фильтр по датам и жанрам, поиск — попробуйте
   «нолан», найдёт по режиссёру.
2. **Карточка фильма.** Описание, актёры, рейтинги, расписание на неделю,
   отзывы зрителей, кнопка «Поделиться» — она собирает ссылку на бота.
3. **Бронирование.** Дата → сеанс → зал 3 × 5. Места четырёх цветов, выбранные
   удерживаются 10 минут, таймер виден. Оставьте заявку.
4. **Админка** (`/admin`, вторая ссылка). Заявка появилась в разделе «Заявки»:
   «Начать обработку» → «Подтвердить». Место в зале сразу становится занятым.
5. **Личный кабинет.** Билет с QR-кодом, статус, история просмотров.
6. **Что меняется без программиста.** Цена, расписание, фильмы, контакты,
   размер зала, правила брони, бонусы — всё в админке. Покажите: измените цену
   в разделе «Цена» и обновите зал.
7. **Языки.** Переключатель RU/UZ в шапке — переводится весь интерфейс.

## Что в демо пусто и почему

- **Галерея зала** — нужны настоящие фотографии. Загружаются в админке,
  раздел «Галерея»; пока их нет, блок на странице «О нас» не показывается.
- **Мелодии** — то же самое, раздел «Мелодии». Ставить туда синтетический
  звук ради демо смысла нет.

## Чего в локальном показе нет

Самого Telegram. Mini App открывается внутри Telegram только по публичному
HTTPS-адресу, поэтому бот в этот сценарий не входит: `WEBAPP_URL` в `.env`
сейчас указывает на старый деплой, который не отвечает. Когда появится
постоянный домен (или временный туннель), бот запускается отдельно:

```powershell
.\.venv\Scripts\python.exe bot.py
```

Токен бота рабочий, проверен: `@NOVA_CINEMA_searchbot`.

## Данные

```powershell
.\.venv\Scripts\python.exe seed_movies.py   # 22 фильма и расписание на неделю
.\.venv\Scripts\python.exe demo_data.py     # заявки, отзывы, бонусы, тексты
```

Оба скрипта безопасно запускать повторно: они не трогают то, что уже есть.
Начать с чистого листа — удалить `nova-dev.db`, затем:

```powershell
.\.venv\Scripts\python.exe -m alembic upgrade head
```

## База данных

Демо работает на локальном файле `nova-dev.db` — ответы мгновенные.

В `.env` рядом лежит закомментированный адрес Supabase: схема там создана и
заполнена теми же данными. Каталог оттуда отдаётся примерно за две секунды —
сервер в Сингапуре, — поэтому для показа он не подходит, а для боевого
развёртывания подходит. Переключение — одна строка в `.env`.
